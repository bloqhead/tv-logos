# tv-logos

Channel logos for a home ErsatzTV setup, in a 90s cable style. They're hosted here so Plex can show them in its Live TV guide: Plex only loads guide images from public addresses.

Generated by a script; edits made here are overwritten. Each file is named `<channel>-<hash>.png`, and the hash changes whenever the image does, so guide apps don't keep showing an old copy.

Fonts used: [Bungee](https://fonts.google.com/specimen/Bungee) and [Archivo Black](https://fonts.google.com/specimen/Archivo+Black), both under the SIL Open Font License.
